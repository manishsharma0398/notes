# Chapter 13: Secrets Management Cheatsheet

### 1. `data "aws_ssm_parameter"` 
**Purpose:** Fetches a value that already exists in AWS Parameter Store dynamically at runtime.
```hcl
data "aws_ssm_parameter" "api_key" {
  name            = "/prasaarit/production/stripe_key"
  
  # When marked true, Terraform dynamically decrypts the KMS key in memory
  with_decryption = true 
}

# The value is accessed via:
# data.aws_ssm_parameter.api_key.value
```

### 2. `aws_ssm_parameter`
**Purpose:** Provisions a *new* string or parameter into AWS from Terraform.
**Warning:** Never use this to provision `SecureString` passwords unless the value is dynamically generated by another Terraform block (like `random_password`).
```hcl
resource "aws_ssm_parameter" "config" {
  name  = "/prasaarit/production/app_url"
  type  = "String"
  value = "https://api.prasaarit.com"
}
```

### 3. The `random_password` Resource
**Purpose:** Generates a secure, cryptographically random password solely in memory during `terraform apply`.
**Best Practice:** Combine this with an `aws_secretsmanager_secret_version` or `aws_ssm_parameter` to generate and vault an RDS Database password without ever a human typing it.

```hcl
resource "random_password" "db_password" {
  length           = 16
  special          = true
  override_special = "_%@"
}

# Save it to SSM so applications can look it up later
resource "aws_ssm_parameter" "db_pass_store" {
  name  = "/db/master_password"
  type  = "SecureString"
  value = random_password.db_password.result
}
```
