# Chapter 22 Notes
**ESM:** Modern module system  
**Named export:** `export const foo`  
**Default export:** `export default`  
**Live bindings:** Exports update, imports reflect  
**Singleton:** Module code runs once  
**Dynamic import:** `await import()`

## One-Sentence
ES modules provide a static import/export system with live bindings that reflect changes, singleton execution, always-strict mode, and support for dynamic imports via async import() for conditional loading.
