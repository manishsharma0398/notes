# Chapter 22 Interview
## Q1: Live Bindings
**Q:** What are live bindings?  
**A:** Exports update, imports reflect changes (not copies)

## Q2: Default vs Named
**Q:** Difference?  
**A:** Default: one per module; Named: multiple, explicit names

## Q3: Dynamic Import
**Q:** Use case?  
**A:** Conditional loading, code splitting, lazy loading
