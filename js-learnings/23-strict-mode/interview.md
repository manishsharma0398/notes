# Chapter 23 Interview
## Q1: Enable Strict
**Q:** How?  
**A:** `"use strict";` at file/function top; automatic in classes/modules

## Q2: Implicit Globals
**Q:** What happens in strict mode?  
**A:** ReferenceError instead of creating global

## Q3: this Value
**Q:** What is this in strict mode function?  
**A:** undefined (not global object)
