# Chapter 18 Notes
**try/catch/finally:** Sync error handling  
**Promises:** Use `.catch()`  
**async/await:** Use try/catch

## Error Types
TypeError, ReferenceError, SyntaxError, RangeError

## One-Sentence
JavaScript error handling uses try/catch/finally for synchronous code and .catch() or try/catch with async/await for asynchronous code, with errors bubbling up the call stack until caught or reaching the global error handler.
