# Chapter 16 Notes
## Async Basics
- **Event loop:** Manages async operations
- **Promises:** Pending → Fulfilled/Rejected
- **async/await:** Syntactic sugar for promises

## One-Sentence
JavaScript handles asynchronous operations through the event loop, which coordinates the call stack with Web APIs and callback/microtask queues, with promises and async/await providing cleaner syntax than callbacks for managing async flow.
