# Chapter 24 Interview
## Q1: undefined vs null
**Q:** Difference?  
**A:** undefined = not assigned; null = intentionally empty

## Q2: typeof null
**Q:** What does typeof null return?  
**A:** "object" (historical bug)

## Q3: ?? vs ||
**Q:** Difference?  
**A:** ?? checks null/undefined only; || checks all falsy values
